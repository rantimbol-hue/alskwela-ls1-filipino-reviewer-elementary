# ALSKwela A&E 2027 – Elementary LS1 Filipino

## Files in the ZIP
- `index.html`: self-contained 90-question mobile-first reviewer (no external libraries)
- `sw.js`: offline-first service worker with dedicated Elementary LS1 Filipino cache
- `manifest.webmanifest`: installed name = **Elementary ALS A&E Reviewer LS 1 - Filipino**
- `icon-192.png`, `icon-512.png`, `.nojekyll`

## Publish using GitHub Pages
1. Create a NEW GitHub repository, suggested: `alskwela-ls1-filipino-reviewer-elementary`.
2. Extract this ZIP. Upload **the individual files inside**, not the ZIP itself, directly to repository root.
3. Go to **Settings → Pages**; deploy from branch `main` and folder `/(root)`.
4. After GitHub publishes HTTPS website, open the link directly in Chrome on Android.
5. Wait until the page confirms offline files have been saved.
6. From Chrome menu install/Add to Home Screen; if only 'Create shortcut' is available, still test it offline.
7. Turn on airplane mode. Reopen through Home Screen icon, answer a question and download a PDF report.
8. Paste the HTTPS URL in ALSKwela Glide card using **Open Link** (not embed) action.

## Notes for teachers
- Questions are independently written practice items mapped to the uploaded 2026 Elementary ALS LS1 Filipino CG.
- 3 sets × 30 questions; balanced random draws contain 9 Easy, 15 Moderate, 6 Challenging and all 17 competencies.
- Professional encouraging Filipino/Taglish feedback appears after answering.
- Export learner responses as PDF directly, or use **Print / Save as PDF** for better preservation of any non-ASCII Filipino characters.
- PDF data and local progress are stored on the learner's own device. No server sync.
- Review answer keys, reading suitability, fairness and explanations before deployment; pilot with learners.
